## 끝말잇기 v95에서 바뀐 것

- **💥 전투 손맛** (끝말잇기 RPG 전투 + 자동사냥)
  - 때리는 순간: 칼 궤적, 불꽃, 파편, 충격파
  - 몬스터: 하얗게 번쩍이고 뒤로 밀려나요
  - 화면: 살짝 흔들리고 잠깐 멈칫해요(히트스톱)
  - 전투 화면 분위기: 빛가루가 떠다니고, 비스듬한 빛줄기가 비쳐요
- **🛡 브레이크 (옥토패스 트래블러 방식)**
  - 방패가 있는 몬스터: 보스 6, 히든 8, 정예 3, 영웅 등급 이상 몬스터 3
  - 단어 하나마다 1칸씩 깨져요. 4글자 이상, 한방단어, PERFECT는 각각 1칸씩 더 깨져요.
  - 방패를 다 깨면 **BREAK!** 몬스터가 2번 공격을 못 하고(기절), 그동안 데미지가 1.5배예요.
- 에디터 "패치" 목록에 `jdfx`(전투 손맛), `jdbrk`(브레이크)가 생겨서 따로 끄고 켤 수 있어요.

## RPG (rpg-v6)에서 바뀐 것

- **3D 액션 RPG** (Three.js 엔진)
  - 메이플처럼 긴 맵이고, 맵 곳곳에 몬스터가 살아요.
  - 18마리를 잡으면 맵 오른쪽 끝에 보스 문이 열려요.
- **도트 맵** (AsLib, CC0)
  - 땅 타일, 나무, 덤불, 꽃, 바위, 수정, 눈 나무를 깔았어요.
  - 테마는 10개이고, 스테이지마다 바뀌어요.
  - 하늘은 듀얼리스트(CC0) 그림이에요.
- 글로브뷰(휘는 땅)는 어지러워서 **껐어요**. 운영자 에디터에서 다시 켤 수 있어요.
- **스킬**
  - 공격: 1·2·3타 연속, 3타는 적을 띄워요
  - 🌀 회오리, ⚡ 뇌전(적 무리에 뛰어들기), ☄ 운석, 💨 구르기(무적)
- **보스 패턴 8가지**
  - 내려찍기, 연속 돌진, 부채꼴, 지뢰밭, 조여 오는 고리, 졸개 부르기, 안전 지대(초록 원), 풍차
  - 바닥에 빨갛게 보이는 곳이 실제로 맞는 범위예요.
- **🛡 브레이크**: 보스·정예·강한 몬스터의 방패를 깨면 기절하고 데미지가 1.5배예요.
- **끝말잇기와 같이 쓰는 것**: 가방·장비창·강화·큐브·변신·동료·뽑기·합성은 끝말잇기 기능을 그대로 써요. 저장도 같이 돼요.
- **영웅 그림**: 걷기 그림이 없는 장비를 입으면, 끝말잇기와 같은 "옷 입힌 그림"으로 보여요. 그래서 장비가 빠져 보이지 않아요.
- **고친 것**
  - 화면 확대 막기: 두 번 톡, 두 손가락 확대
  - 숨겨진 창 때문에 게임이 멈추던 문제
- **⚙ 설정 → 🔍 그림 상태**: 맵, 몬스터, 변신, 영웅 그림을 무엇을 불러왔는지 한눈에 보여요. 여기서 다시 불러올 수도 있어요.
- **🔐 운영자 모드**
  - 처음 비밀번호는 `jungdo2`예요. 꼭 바꿔 주세요.
  - 할 수 있는 것: 무적, 한 방, 보스 바로 가기, 모든 스테이지 이동, 골드·뽑기권·큐브 넣기, 숫자 에디터
  - 숫자 에디터에서 [파일로 받기] → `rpg-config.json`을 rpg 저장소에 올리면 모두에게 적용돼요.

## 아직 확인 못 한 것 / 다음에 할 것

- 실제 휴대폰에서는 아직 확인 못 했어요. 확인한 것은 테스트용 브라우저뿐이에요.
- 마지막 수정 두 가지(방패 글자 "방패 n", 옷 입힌 영웅 크기)도 테스트 브라우저에서 확인했어요.
- 효과음(m4a)이 실제로 나는지는 휴대폰에서 확인이 필요해요. 안 나오는 기기에서는 직접 만든 소리로 대신 나와요.
- 영웅 걷기 그림은 자무주 수집기로 더 모을수록 많아져요. 지금 받아 둔 것은 무기 845개, 투구 766개 등이에요.
- "버튼을 누르면 화면이 계속 확대되고 안 넘어가는" 문제가 또 생기면, 화면 사진이나 영상을 보내 주세요.
